Research Proposal

Overview

The Zwicky Transient Facility (ZTF) generates a massive stream of alerts, necessitating automated classification systems. Traditional methods often overlook the "observation context" (e.g., seeing conditions, moon illumination, airmass), which critically biases detectability. This research proposes a Self-Supervised Contrastive Learning framework.

Methodology: Contrastive Learning (SimCLR)

We employ a tabular SimCLR approach. By treating different augmentations (noise, jitter, masking) of the same observation metadata as "positive pairs", the model learns to map observations to a latent space where similar observing conditions cluster together, independent of the specific transient object type. This allows for robust "Detectability" labeling.

Key Objectives

  • Develop an Observation-Context Encoder using SimCLR.
  • Generate latent embeddings for all ZTF observations.
  • Cluster embeddings to discover inherent "Detectability Modes".
  • Integrate with image data for multi-modal classification (Future Work).

System Overview

1. Observe

ZTF Telescope captures the sky. Data includes Field ID, Filter, Seeing, Airmass, and Exposure time.

2. Data Ingestion

Raw observation metadata is standardized. Continuous variables are scaled; categorical IDs are encoded.

3. Encoder

Our pre-trained SimCLR Encoder processes the feature vector into a high-dimensional embedding (256-dim).

4. Clustering

The embedding is mapped to a cluster (e.g., Cluster 5: "High Airmass, Low Seeing") to determine data quality.
